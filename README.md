# 🧪预设工坊测试版

> 这是个人开发测试通道，功能可能尚未完成。正式用户请安装
> [🧩预设工坊](https://github.com/yui-ovo/ST-Preset-Workshop)。

适用于 SillyTavern 的双端预设管理扩展，首个扩展版本由酒馆助手脚本 **v2.53** 无损迁移而来，当前测试版本为 **v2.94.0-test.54**。

本仓库从正常浏览器版复制，用于在大功能完成前独立开发和验证，不包含 Gecko 后台 iframe 实验补丁。Firefox、雨见等 Gecko／GeckoView 手机浏览器请改用 [Gecko 兼容版](https://github.com/yui-ovo/ST-Preset-Workshop-Gecko)。

测试版和正式版共用运行实例锁与本地设置。请勿同时启用两个版本；测试时关闭正式版，完成测试后再切换回来。

## 依赖

本扩展继续使用酒馆助手提供的脚本运行环境，因此需要先安装并启用：

- [酒馆助手（JS-Slash-Runner）](https://github.com/N0VI028/JS-Slash-Runner)

安装扩展版前，请在酒馆助手中停用旧的 `🧩预设工坊｜双端适配v2.53` 脚本，避免重复运行。

## 安装

1. 打开 SillyTavern 的“扩展”。
2. 选择“安装扩展”。
3. 粘贴测试仓库的 Git URL：`https://github.com/yui-ovo/yushe-gongfang-ceshi.git`。
4. 安装完成后刷新 SillyTavern。

## 当前版本

- 扩展版本：`2.94.0-test.54`
- 迁移基准：`🧩预设工坊｜双端适配v2.53`
- 第一阶段保持原脚本行为，不在迁移过程中重写业务逻辑。
- iOS、iPadOS 与 TauriTavern（WKWebView）会自动启用稳定滚动模式；安卓继续使用原有离屏渲染优化。
- 魔法棒跟随主题时会忽略透明假黑，优先采用酒馆主题色，并同时校验面板、条目卡片与文字对比度。
- 打开缝合后，下方预设的分组内、分组外普通条目开关都会立即同步；柏宝箱分组总开关保持原行为。
- 进入多选并勾选条目后，展开任意条目点击正文旁的 `S`，可把所有已选普通条目批量转换为同名变量；转换后的正文会立即同步到当前分组视图，`G` 保持原行为。
- 多选状态下的 `S` 菜单新增“批量重命名变量”：只改已选条目的变量名；部分拆分时保留旧 G 并新增新 G，全部改名时同步改旧 G，也可选择只改 S，整次操作支持撤销。
- 名为“获取变量”等条目中的空 `setvar` 会被识别为变量登记而非正文 S：部分拆分时保留旧登记并新增新登记，全部改名时同步替换，且不会重复生成已有登记。
- 正文工具栏新增斜线 `S` 的“去除变量格式”：单条或多选均可把完整 setvar 外壳还原为普通正文，并可选择只还原正文，或同时清理已经没有正文 S 使用的对应 G 与“获取变量”中的空变量登记。
- 多选模式下每个分组头新增双√“组内全选”：未选或部分选中时补选整组，整组已选时一键取消，并用主题色区分部分选中与全部选中；主预设自带分组不再显示仅影响工坊本地的“解散分组”。
- 修正部分手机端已显示条目复选框、却未出现“组内全选”按钮的问题：现在按条目的真实多选状态识别。
- 在同一分组内用工坊连续范围创建新分组时，新组会作为一层子分组留在原位置；此前已创建、仍能确认原外层归属的工坊范围组也会自动归位。解散子组后条目按原顺序回到外层分组；跨分组或整组选中时仍创建普通外层分组。
- 安卓打开布局调节框后，纵向滑动会继续滚动，只有明确的横向手势或轻点轨道才会修改滑杆。
- 安卓自定义“普通条目高度”时会关闭条目自身的离屏尺寸缓存，避免缩小条目后互相重叠；恢复默认高度后继续使用原有性能优化。
- “预设名称框长度”与“分支名称框长度”使用固定且独立的调节范围；切换布局或调节其中一项不会再锁死、夹断或放大另一项。
- 在预设／世界书布局之间切换后，“预设名称框长度”只改变卡片内部名称区域，外层标题卡片与顶部工具栏宽度保持不变。
- 布局调节弹窗在魔法棒模式下会读取工坊当前实际背景，不再把 `auto` 误判为浅色，并可随美化重绘同步明暗。
- 世界书页以拖拽缝合为主：预设／世界书切换取代复制／移动按钮，两个入口使用相连的分段按钮且切换时不再弹出说明通知；世界书工具栏恢复多选与可用撤销，世界书模式隐藏主题按钮组。
- 手机世界书页把原有日间／夜间／魔法棒三态按钮单独移入上方工具栏：预设模式位于世界书与平铺按钮之间，世界书模式位于世界书与多选按钮之间，不再把旁边的悬浮按钮开关一起带入。
- 世界书选择弹窗支持输入世界书名或角色名；主要及额外角色绑定都会参与匹配，结果分为“角色绑定世界书”和“未绑定角色的世界书”，并在绑定项下标出对应角色。
- 世界书搜索弹窗会复制工坊当前日间、夜间或魔法棒实际主题；两个绑定分类默认收起、点击标题展开，输入搜索内容时自动展开有结果的分类。
- 角色绑定世界书优先按原名精确识别，未命中时再统一处理首尾空格和 Unicode；兼容角色卡世界书名称末尾藏有空格的情况。
- 上、下世界书卡片的名称放大镜旁新增铅笔，会先打开酒馆原生的世界书重命名流程；完成后工坊自动刷新同名的上下卡片。
- 世界书条目搜索改为紧凑工具条：关键词会高亮，数字显示当前／总匹配数，上下箭头可依次跳转；可在“全／仅标题／仅内容”之间切换，正文命中会自动展开并选中对应文字。
- iOS 在世界书条目搜索中输入、删除或使用中文输入法时，只会更新结果区，不会重建输入框，因此不会再因为输入法组合文字而收起键盘。
- 世界书条目搜索的匹配数移入搜索框右侧，腾出的位置新增浅色循环箭头；点击后展开替换栏。替换框获得焦点时“替换／替换全部”变深；两项均遵守“全／仅标题／仅内容”的当前范围，空替换内容表示删除文字，替换全部删除前会提示影响处数，并支持一次撤销。
- 世界书搜索会在已展开、且正文确有命中的条目中显示主题色正文高亮；上下箭头当前指向的词会以更亮的强调色和描边显示，并自动滚到可见位置。正文点击后恢复正常编辑框，失焦后重新显示高亮；夜间与魔法棒均取当前主题强调色而非固定灰色。
- 日间模式的世界书搜索命中使用参考文字选中效果的浅冰蓝底、深色字；上下箭头当前指向的命中使用更深的天蓝底、深色字，不再使用描边或发光。夜间与魔法棒不套用这组日间颜色，继续跟随各自主题。
- 手机上的世界书正文获得编辑焦点后，会暂时上移所在卡片，将文本框放到键盘上方；失焦后自动归位。世界书范围替换／删除完成后，顶部撤销按钮会立即启用；日间替换框聚焦时的两个操作按钮改为半深度的柔和灰蓝。
- 世界书多选时，“撤销”工具位会原地切换为“删除所选”；退出多选立即恢复撤销。两者共用同一位置，删除后退出多选仍可撤回。
- 世界书模块改为首次点工具栏“世界书”时才载入；只使用预设时不会解析世界书代码或注册世界书监听。首次打开后保留本轮会话模块缓存，离开世界书工作区时记住上次的上卡类型与世界书选择，并在下次进入时重新读取内容。
- 世界书多选新增列表上方的“全选／取消全选”。全选会勾选整本世界书（正在搜索时则只勾选搜索结果）；拖动任一已勾选条目会保持世界书原有顺序，整体拖到另一张卡片。预设与世界书的多选拖动统一改为跟手双层卡：灰色上下箭头、“拖动 N 条”和数字圆。后层与前层原位重叠，以中心为轴顺时针旋转 4°，形成清晰的交叉叠放，并压薄为轻量比例；日间使用白瓷半透明双层卡与柔灰文字，夜间使用深蓝灰玻璃双层卡与亮色文字；魔法棒按实际主题明暗自动选择，且继续压缩原生拖拽截图以避开 WebKit 透明区域的黑底；单选维持原有拖拽反馈。
- 顶部“预设／世界书”切换中，世界书处于选中态时强制使用与预设一致的纯白高对比图标；夜间和任意魔法棒主题不会再被主题字色覆盖，非选中态仍跟随当前主题。
- 世界书条目详情采用与预设接近的紧凑字号和控件比例，条目开关与蓝／绿灯按钮同步缩小；`@D` 的系统／用户／助手身份合并回位置选项，正文默认显示更多行，放大编辑会读取当前日间、夜间或魔法棒实际配色。
- 世界书正文的放大编辑标题栏内置本次输入撤销，连续输入会按短暂停顿分步记录；保存后仍可继续使用世界书卡片原有的操作撤销。
- 预设与世界书的放大编辑统一为只显示正文的共用编辑框；手机四周保留适当空隙，并保留条目名、字数、本次编辑撤销、取消和完成。
- 世界书条目拖入预设时会转换为“系统／相对”的普通预设条目，按落点插入并立即刷新上方列表；拖拽落点线会在结束后清理。
- 世界书拖入预设改为调用工坊原生跨卡片事件，同步更新上方可见数组、分组状态与原生撤销；直接保存仅作为旧环境兜底。
- 工坊主面板显式开放世界书拖入桥，世界书不再猜测 Vue 组件层级；拖入后直接复用原生预设缝合处理器并立即生成卡片。
- 世界书之间复制／移动时完整保留原条目字段，只重新分配目标 UID；拖到条目上半或下半会显示对应的蓝色落点线，并准确插到线的位置，多选条目会按原顺序作为整体插入。只有拖到列表末尾空白处才会追加到最后，不再让整张目标卡片边框变色。
- 条目间距小于 `3px` 时，拖拽落点线自动切换到目标卡片内侧；正常间距继续使用原版外部主题色细线。
- 手机对比预设时，点击“内容不同”或“正文相似”会自动展开两侧目标分组并读取正文，不再要求先切换为平铺显示。
- 对比模式下，差异条目保留红色、黄色或蓝色边框，同时叠加原版随主题变化的上方／下方细落点线。
- TauriTavern iOS 会为“对比结果详情”和“预设正则脚本·搬运”自动避开灵动岛与底部安全区；TauriTavern Windows 会改用仅限工坊内部的指针拖拽，避开原生文件拖放的禁止标志。
- TauriTavern iOS 的展开条目编辑器沿用旧版右侧安全宽度并强制中文换行；兼容宿主最早写入的平台标记，并完整约束展开条目的真实过渡容器，避免外层超宽后再裁掉右侧内容。只有“内容正文”标题栏实际放不下时，字符数与全屏按钮才移到下一行，其他浏览器与设备不受影响。
- 测试版“世界书”改为复用工坊原有上下双卡片：上方可切换预设／世界书，下方固定世界书；切换模式时只读取当前所需数据，不再叠加独立窗口。

## 目录

- `manifest.json`：SillyTavern 扩展清单。
- `dist/index.js`：标准 SillyTavern 扩展启动器。
- `dist/workshop-v2.94.js`：当前业务入口；增加小间距下的内部拖拽落点线，不强制撑开条目。
- `dist/worldbook-stitch-test3.js`：测试版世界书双卡片与预设／世界书双向缝合逻辑。
- `dist/workshop-v2.53.js`：由 v2.53 JSON 的 `content` 原样提取的迁移基准。
- `bridge/`：复用酒馆助手运行环境所需的兼容桥。
- `legacy/`：迁移前的原始酒馆助手脚本，仅用于校验和回退。
- `scripts/validate.mjs`：发布前的基础完整性检查。
