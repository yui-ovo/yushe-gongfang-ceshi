## 世界书快照第一版

- 世界书标题栏的相机打开快照页；点击「选择世界书」显示上下分区：角色绑定世界书、已挂全局且未绑定角色的世界书。
- 快照面板可以切换「预设」「角色世界书」「全局世界书」。预设原有的绑定操作收进「⋯」。
- 选择一本世界书后新建快照，只编辑条目开关。草稿不改原书，保存后应用，取消不写入。快照不复制正文、关键词或排序；新增条目保留当前开关，删除的条目不重建。
- 创建快照默认不绑定角色。在对应角色聊天中，用「⋯ → 绑定当前角色并应用」立即应用，以后进入角色自动应用。返回主页或切换角色时先恢复进入前状态，再应用新角色的绑定方案。
- 多个角色可以共用一本书，但同一个角色对同一本书只绑定一份快照。第一版不添加聊天专属世界书快照或群聊绑定。
- 「全局世界书 → 世界书分组」可以选择尚未挂全局的未绑定角色世界书。开启会统一挂载；关闭保留原本手动挂着和其他开启分组需要的书。先关闭分组才能改成员或删除。
- 自动切换监听聊天变更事件，不轮询世界书正文。世界书未保存的普通编辑会阻止覆盖；编辑快照时切换角色会保留草稿并阻止保存到错误上下文，取消草稿后继续切换。

快照和恢复记录保存在当前浏览器的本地存储，应用后的世界书与全局挂载会写入酒馆。多设备或多标签页同时调整同一本书不属于第一版的隔离范围。开启分组期间若在酒馆原生页面反复手动调整相同挂载，无法可靠识别一次「重新手动接管」；建议先关闭分组再手动管理。

本仓库是正常浏览器版，不包含 Gecko 后台 iframe 实验补丁。Firefox、雨见等 Gecko／GeckoView 手机浏览器请改用 [Gecko 兼容测试版](https://github.com/yui-ovo/ST-Preset-Workshop-Gecko)，请勿同时安装两个版本。

- 修复快照模式切换条目或柏宝箱分组后，保存退出偶尔没有恢复进入前状态的问题：录制期间的全部开关现在只修改隔离画面，不再提前写入命名预设或酒馆原生分组存储；进入前即使已有未保存修改，也会恢复该草稿并保留原有保存状态。
- 快照录制改为真正的隔离事务：每次进入时冻结完整主预设基线，保存或取消后直接整体恢复，不再读取退出瞬间可能滞后的 Vue 草稿，避免第二次制作快照时偶发残留快照开关。
- 修复从酒馆主预设栏相机第一次应用快照时，隐藏工坊旧草稿可能令应用被误判为零变化、主预设开关不刷新的问题；原生入口现在以酒馆当前预设为准，并始终完成一次幂等同步与重绘。
- 修复从酒馆主预设栏相机进入快照后，点击应用、绑定等弹层按钮会被酒馆误判为点击菜单外部、进而关闭主预设页面的问题。
- 快照模式现在只保留条目开关与柏宝箱分组开关；条目编辑、收藏、复制、删除、框选分组及分组改名／解散按钮均会隐藏，退出快照模式后恢复正常。
- 修复比对详情中“仅上侧／仅下侧预设存在”的条目位于折叠分组时无法跳转的问题；现在会先自动展开对应分组，再滚动并高亮准确条目，同名条目也按出现顺序定位。
- 修复普通预设条目多选拖动时因勾选先后与逐条落位造成的内部乱序；现在无论向上或向下、落在目标上方或下方，都会保持条目在当前列表中的原始相对顺序。
- 修复 iOS 键盘弹出时“保存快照”名称输入框将底部弹层推离可视区域的问题；安卓、Gecko 与电脑端继续沿用原定位路径。
- 在酒馆主页手动应用的快照会作为“主页快照”记忆；角色或聊天绑定会临时覆盖并在绑定当下立即生效，回到 `No chat selected` 或进入无绑定聊天时恢复主页快照，主页快照失效后才回退预设默认。

- 手机夜间模式的顶部工具按钮在未选中时不再显示一格一格的底框，与日间模式保持一致；当前启用、保存高亮和按压状态仍有反馈，取消多选后也不会残留左侧竖线。
- 手机端原生预设与上方世界书统一为固定标题外框：默认会优先缩短内部名称，确保搜索和小铅笔可见；手动调节“预设名称框长度”时只改变内部名称，下方世界书不受影响。
- 标题右侧工具会按当前屏幕剩余宽度平均分布；不常用的导入、导出仍保留在可横划到的右侧区域。
- 工坊不再把全局顶部通知强制缩短为 0.3 秒，通知开启时会遵循酒馆自身的显示时长，也不会影响其他插件的通知速度。
- 布局调节页底部新增“顶部通知”开关；关闭后会记住选择并静默预设工坊与世界书的顶部小通知，不影响酒馆和其他插件。
- 精简日常通知：保存、改名、切换、单条收藏／复制等已有可见结果的操作不再重复弹窗；错误、风险提醒、撤销、批量操作和跨模块同步结果继续保留。
- 新增世界书入口：支持世界书条目之间拖动缝合、世界书条目拖入预设自动转换，并支持同一本世界书内的视觉排序。
- 世界书支持角色绑定搜索、查找替换、展开条目复制／删除、蓝绿灯切换，以及保存前草稿与保存按钮高亮提示。
- SillyTavern 1.18 及以上继续使用原生世界书枚举接口；1.14 等旧版缺少该接口时，会按酒馆原生方式读取世界书名称。
- 世界书编辑仅在打开“世界书”时启用；只使用预设缝合时不会额外开启这套模块。
- 迁移基准：`🧩预设工坊｜双端适配v2.53`
- 第一阶段保持原脚本行为，不在迁移过程中重写业务逻辑。
- iOS、iPadOS 与 TauriTavern（WKWebView）会自动启用稳定滚动模式；安卓继续使用原有离屏渲染优化。
- 魔法棒跟随主题时会忽略透明假黑，优先采用酒馆主题色，并同时校验面板、条目卡片与文字对比度。
- 打开缝合后，下方预设的分组内、分组外普通条目开关都会立即同步；柏宝箱分组总开关保持原行为。
- 进入多选并勾选条目后，展开任意条目点击正文旁的 `S`，可把所有已选普通条目批量转换为同名变量；转换后的正文会立即同步到当前分组视图，`G` 保持原行为。
- 多选变量条目后可批量重命名变量，并按剩余同名正文安全保留、新增或同步 `G` 与同名空变量项；斜线 `S` 可去除变量格式并选择是否清理失效项。
- 预设条目正文支持只显示正文的留边全屏编辑，跟随当前主题，并提供本次输入撤销、取消与保存。
- 单独更新本扩展时会保留酒馆原生成功提示并自动刷新；批量更新时不会抢先打断其他扩展。
- 多选模式下，每个分组标题提供双勾按钮，可一键选择或取消本组全部条目；在主预设分组内把连续条目组成工坊分组时，子分组保持在原位置。
- TauriTavern iOS 仅在展开编辑器实际放不下时收窄内容区并让字符数与全屏按钮换行，避免正文、字符数或全屏按钮被右侧裁掉。
- 安卓打开布局调节框后，纵向滑动会继续滚动，只有明确的横向手势或轻点轨道才会修改滑杆。
- 安卓自定义“普通条目高度”时会关闭条目自身的离屏尺寸缓存，避免缩小条目后互相重叠；恢复默认高度后继续使用原有性能优化。
- “预设名称框长度”与“分支名称框长度”使用固定且独立的调节范围；切换布局或调节其中一项不会再锁死、夹断或放大另一项。
- 条目间距小于 `3px` 时，拖拽落点线自动切换到目标卡片内侧；正常间距继续使用原版外部主题色细线。
- 手机对比预设时，点击“内容不同”或“正文相似”会自动展开两侧目标分组并读取正文，不再要求先切换为平铺显示。
- 对比模式下，差异条目保留红色、黄色或蓝色边框，同时叠加原版随主题变化的上方／下方细落点线。
- TauriTavern iOS 会为“对比结果详情”和“预设正则脚本·搬运”自动避开灵动岛与底部安全区；TauriTavern Windows 会改用仅限工坊内部的指针拖拽，避开原生文件拖放的禁止标志。

## 目录

- `manifest.json`：SillyTavern 扩展清单。
- `dist/index.js`：标准 SillyTavern 扩展启动器。
- `dist/workshop-v3.02.js`：当前业务入口；包含最终“开关快照”、手机标题栏与可视区域定位，以及电脑主面板／分屏适配。
- `dist/workshop-v3.01.js`：上一版业务入口，保留用于版本回溯。
- `dist/preset-content-editor.js`：独立的预设正文全屏编辑器，不包含世界书功能。
- `dist/workshop-v2.53.js`：由 v2.53 JSON 的 `content` 原样提取的迁移基准。
- `bridge/`：复用酒馆助手运行环境所需的兼容桥。
- `legacy/`：迁移前的原始酒馆助手脚本，仅用于校验和回退。
- `scripts/validate.mjs`：发布前的基础完整性检查。

第三方扩展能够在 SillyTavern 页面中运行代码。请只从本项目的正式仓库安装，并在更新前查看版本说明。
