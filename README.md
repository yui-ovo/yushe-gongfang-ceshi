# 🧪预设工坊测试版

> 这是个人开发测试通道，功能可能尚未完成。正式用户请安装
> [🧩预设工坊](https://github.com/yui-ovo/ST-Preset-Workshop)。

适用于 SillyTavern 的双端预设管理扩展，首个扩展版本由酒馆助手脚本 **v2.53** 无损迁移而来，当前测试版本为 **v2.94.0-test.11**。

本仓库从正常浏览器版复制，用于在大功能完成前独立开发和验证，不包含 Gecko 后台 iframe 实验补丁。Firefox、雨见等 Gecko／GeckoView 手机浏览器请改用 [Gecko 兼容版](https://github.com/yui-ovo/ST-Preset-Workshop-Gecko)。

测试版和正式版共用运行实例锁与本地设置。请勿同时启用两个版本；测试时关闭正式版，完成测试后再切换回来。

## 依赖

本扩展继续使用酒馆助手提供的脚本运行环境，因此需要先安装并启用：

- [酒馆助手（JS-Slash-Runner）](https://github.com/N0VI028/JS-Slash-Runner)

安装扩展版前，请在酒馆助手中停用旧的 `🧩预设工坊｜双端适配v2.53` 脚本，避免重复运行。

## 安装

1. 打开 SillyTavern 的“扩展”。
2. 选择“安装扩展”。
3. 粘贴测试仓库的 Git URL：`https://github.com/yui-ovo/yushe-gongfang-ceshi.git`。
4. 安装完成后刷新 SillyTavern。

## 当前版本

- 扩展版本：`2.94.0-test.11`
- 迁移基准：`🧩预设工坊｜双端适配v2.53`
- 第一阶段保持原脚本行为，不在迁移过程中重写业务逻辑。
- iOS、iPadOS 与 TauriTavern（WKWebView）会自动启用稳定滚动模式；安卓继续使用原有离屏渲染优化。
- 魔法棒跟随主题时会忽略透明假黑，优先采用酒馆主题色，并同时校验面板、条目卡片与文字对比度。
- 打开缝合后，下方预设的分组内、分组外普通条目开关都会立即同步；柏宝箱分组总开关保持原行为。
- 进入多选并勾选条目后，展开任意条目点击正文旁的 `S`，可把所有已选普通条目批量转换为同名变量；转换后的正文会立即同步到当前分组视图，`G` 保持原行为。
- 安卓打开布局调节框后，纵向滑动会继续滚动，只有明确的横向手势或轻点轨道才会修改滑杆。
- 安卓自定义“普通条目高度”时会关闭条目自身的离屏尺寸缓存，避免缩小条目后互相重叠；恢复默认高度后继续使用原有性能优化。
- “预设名称框长度”与“分支名称框长度”使用固定且独立的调节范围；切换布局或调节其中一项不会再锁死、夹断或放大另一项。
- 在预设／世界书布局之间切换后，“预设名称框长度”只改变卡片内部名称区域，外层标题卡片与顶部工具栏宽度保持不变。
- 布局调节弹窗在魔法棒模式下会读取工坊当前实际背景，不再把 `auto` 误判为浅色，并可随美化重绘同步明暗。
- 世界书页以拖拽缝合为主：预设／世界书切换取代复制／移动按钮，两个入口使用相连的分段按钮且切换时不再弹出说明通知；世界书工具栏恢复多选与可用撤销，世界书模式隐藏主题按钮组。
- 世界书条目详情采用与预设接近的紧凑字号和控件比例，条目开关与蓝／绿灯按钮同步缩小；`@D` 的系统／用户／助手身份合并回位置选项，正文默认显示更多行，放大编辑会读取当前日间、夜间或魔法棒实际配色。
- 世界书正文的放大编辑标题栏内置本次输入撤销，连续输入会按短暂停顿分步记录；保存后仍可继续使用世界书卡片原有的操作撤销。
- 预设与世界书的放大编辑统一为只显示正文的共用编辑框；手机四周保留适当空隙，并保留条目名、字数、本次编辑撤销、取消和完成。
- 条目间距小于 `3px` 时，拖拽落点线自动切换到目标卡片内侧；正常间距继续使用原版外部主题色细线。
- 手机对比预设时，点击“内容不同”或“正文相似”会自动展开两侧目标分组并读取正文，不再要求先切换为平铺显示。
- 对比模式下，差异条目保留红色、黄色或蓝色边框，同时叠加原版随主题变化的上方／下方细落点线。
- TauriTavern iOS 会为“对比结果详情”和“预设正则脚本·搬运”自动避开灵动岛与底部安全区；TauriTavern Windows 会改用仅限工坊内部的指针拖拽，避开原生文件拖放的禁止标志。
- 测试版“世界书”改为复用工坊原有上下双卡片：上方可切换预设／世界书，下方固定世界书；切换模式时只读取当前所需数据，不再叠加独立窗口。

## 目录

- `manifest.json`：SillyTavern 扩展清单。
- `dist/index.js`：标准 SillyTavern 扩展启动器。
- `dist/workshop-v2.94.js`：当前业务入口；增加小间距下的内部拖拽落点线，不强制撑开条目。
- `dist/worldbook-stitch-test3.js`：测试版世界书双卡片与预设／世界书双向缝合逻辑。
- `dist/workshop-v2.53.js`：由 v2.53 JSON 的 `content` 原样提取的迁移基准。
- `bridge/`：复用酒馆助手运行环境所需的兼容桥。
- `legacy/`：迁移前的原始酒馆助手脚本，仅用于校验和回退。
- `scripts/validate.mjs`：发布前的基础完整性检查。

## 安全说明

第三方扩展能够在 SillyTavern 页面中运行代码。本仓库仅供个人测试；对外发布请使用正式仓库。
